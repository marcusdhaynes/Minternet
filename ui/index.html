◈Secret Bookmarks

A separate encrypted vault. Site addresses and real titles never appear in the bookmark list.

Change Secret Folder Password

Changing the folder password securely re-encrypts all current-format bookmarks. Older bookmarks using former separate codes can be upgraded using those codes.

Reset Secret Folder — Permanent Deletion

This is NOT password recovery. Without the current password, Minternet must destroy the entire Secret Bookmarks vault: all secret bookmarks, optional labels, subfolders and encrypted entry data. Normal bookmarks and saved website passwords are unaffected. SSDs, backups and snapshots may retain historical copies even after overwriting.

Use a strong, preferably random 16-character folder password. Secret Bookmarks use this password; a second code is not required. Your Optional Visible Name can also be included in each bookmark's encryption key.

Upgrade Older Bookmarks

Only bookmarks saved by older Minternet versions may need a one-time migration using their former entry code.
